Nexus CLI 自动重启应用程序
============================

版本: 1.0
作者: Nexus CLI Team

功能说明:
--------
此应用程序用于自动启动和管理 Nexus CLI 的批量处理任务，支持：
- 自动重启功能（每40分钟重启一次）
- 优雅关闭（20秒等待时间）
- 最大并发80个节点
- 系统要求检查
- 错误处理和用户友好的界面

使用前准备:
----------
1. 确保已编译 Nexus CLI：
   cd ~/nexus-cli/clients/cli
   cargo build --release

2. 创建节点列表文件：
   mkdir -p ~/.nexus
   echo "你的节点ID列表" > ~/.nexus/nodes.txt

3. 双击此应用程序即可启动

配置说明:
--------
- 节点文件位置: ~/.nexus/nodes.txt
- 重启间隔: 40分钟
- 优雅关闭时间: 20秒
- 最大并发节点数: 80

如需修改配置，请编辑应用程序包内的脚本文件。

技术支持:
--------
如有问题，请查看应用程序输出的错误信息。
