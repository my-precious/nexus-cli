# 暂停/恢复功能使用说明

## 功能概述

在 Nexus CLI 的动态挖矿监控界面中，新增了按空格键暂停/恢复日志刷新的功能。

## 使用方法

### 暂停日志刷新
- 在监控界面运行时，按 **空格键** 即可暂停日志刷新
- 暂停时，界面标题会显示 `⏸️ PAUSED` 标识
- 暂停期间，节点状态更新不会触发界面刷新

### 恢复日志刷新
- 在暂停状态下，再次按 **空格键** 即可恢复日志刷新
- 恢复时，界面标题恢复正常显示
- 恢复后，所有待更新的节点状态会立即刷新显示

## 界面提示

### 标题栏状态
- 正常状态：`🚀 Nexus Dynamic Mining Monitor - 2025-01-11 08:23:39`
- 暂停状态：`🚀 Nexus Dynamic Mining Monitor - 2025-01-11 08:23:39 ⏸️ PAUSED`

### 操作提示
界面底部会显示：
```
💡 Press Ctrl+C to stop all miners | Space: Pause/Resume | n/p: Next/Prev page
```

### 状态切换消息
- 暂停时：`⏸️  日志刷新已暂停 - 按空格键恢复`
- 恢复时：`▶️  日志刷新已恢复`

## 技术实现

### 核心组件
- `EnhancedDisplay` 结构体中的 `is_paused` 原子布尔值
- 键盘监听任务中的空格键处理逻辑
- 节流刷新任务中的暂停检查

### 优势
1. **实时响应**：无需等待，按键立即生效
2. **状态保持**：暂停期间节点状态继续更新，只是不刷新显示
3. **内存友好**：暂停时减少不必要的渲染操作
4. **用户体验**：可以暂停查看特定状态，便于分析问题

## 适用场景

1. **调试分析**：暂停查看特定时间点的节点状态
2. **性能优化**：在系统负载高时暂停刷新
3. **状态检查**：暂停后仔细查看节点状态信息
4. **截图记录**：暂停后截图记录当前状态

## 注意事项

- 暂停功能只影响界面刷新，不影响节点运行
- 暂停期间节点状态仍会正常更新，恢复后会显示所有累积的更新
- 与其他键盘快捷键（n/p/数字键）兼容使用
- 程序退出时暂停状态不会保存
